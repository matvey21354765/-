## Что работает

| Площадка | Как получаем | Результат в бою |
|---|---|---|
| **Авито** | простой `requests` БЕЗ cookies + webJSON, многостранично | 50–250 объявлений |

## Авито: ключевые правила

### 1. НЕ отправлять cookies
Главный урок. Выгоревшие cookies **сами вызывают 403** — запрос без них проходит.
Проверено и в бою, и по замерам сообщества (без cookies 200 за 0.77с, с ними 403).

Рабочий рецепт (из версии 03.07.2026, `_avito_july_scraper`):

```python
_HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ... Chrome/124.0.0.0 Safari/537.36",
    "Accept": "text/html,application/xhtml+xml,*/*;q=0.8",
    "Accept-Language": "ru-RU,ru;q=0.9",
    "Accept-Encoding": "gzip, deflate, br",
    "Referer": "https://www.avito.ru/",
}
requests.get(url, timeout=8, headers=_HEADERS, proxies=_avito_proxies())
```

Никакой TLS-имперсонации, никаких `sec-ch-ua`, никаких cookies. URL обязательно
с `seller_type=1`, при пустом ответе — повтор без `pmin/pmax`.

### 2. Беречь IP — это главное
Авито (Qrator) банит **подсеть целиком**, а не отдельный адрес. Что сжигает IP:

- **параллельные запросы** — 5 страниц одновременно с одного адреса = явный бот.
  Только последовательно, с паузой 1.2–2.5с;
- **много повторов** — было 6 попыток на страницу × 5 страниц = 30+ запросов за
  поиск. Сейчас 2 повтора (`AVITO_HTML_RETRIES`);
- **перебор мёртвых эндпоинтов** — мобильный API `m.avito.ru/api/N/items` мёртв
  (`route not found` / 403), выключен через `AVITO_ENABLE_MOBILE_API=0`;
- если первая страница заблокирована — остальные **не запрашиваются**.

### 3. Что НЕ работает (проверено, не тратьте время)
- мобильный API приложения — маршруты сняты;
- поисковики (DuckDuckGo/Mojeek/Bing) — отдают заглушки, ссылок на объявления нет;
- Playwright — капча и зависания, к тому же медленно;
- rest-app.net — лента «новое по всей РФ», после фильтра по городу остаётся ноль
  (подтвердилось снова 05.08.2026: при `AVITO_PROVIDER=rest_app` в боте было
  «Avito: 0…3». Теперь, если по городу из ленты набралось меньше
  `AVITO_MIN_REGION_ITEMS` объявлений, бот автоматически дочитывает настоящим
  поиском webJSON — см. `_avito_direct_region_search`. Правильная настройка
  по-прежнему `AVITO_PROVIDER=webjson`. С 06.08.2026 код сам приводит
  `rest_app` к `webjson` — вернуть прежнее поведение можно только через
  `AVITO_FORCE_PROVIDER=1`. Провайдер по умолчанию, если переменная не задана,
  теперь тоже `webjson`, а не `disabled`);
- капча Авито публично не решается никем — все рабочие парсеры обходят её
  репутацией IP.

## Auto.ru: ключевые правила

Яндекс режет по **двум** признакам: «грязный» IP **и** не-браузерный TLS-отпечаток.
Обычный `requests` ловит капчу даже с чистого российского адреса.

Рабочий метод (`_autoru_cffi_fetch`): `curl_cffi` с `impersonate="chrome124"`,
сначала GET страницы листинга (прогревает cookie `spravka`), затем разбор
`__NEXT_DATA__` / inline JSON. Страницы — последовательно, в той же сессии,
с ограничением по времени (`AUTORU_BUDGET_SEC`).

Порядок выходов: прокси → **напрямую**. Прямой выход обязателен: мобильный прокси
регулярно отваливается по таймауту, и без этого шага Auto.ru «временно недоступен».

## Переменные окружения

### Обязательные
```
PROXY_URL=http://логин:пароль@mproxy.site:ПОРТ    # мобильный или серверный прокси
PROXY_ROTATE_URL=https://changeip.mobileproxy.space/?proxy_key=...   # только для мобильного
AVITO_PROVIDER=webjson
```

### Настройки глубины и времени
```
AVITO_PAGES=10              # страниц Авито за поиск
AUTORU_PAGES=8              # страниц Auto.ru
AUTORU_BUDGET_SEC=35        # бюджет времени Auto.ru (страница ~2.2 МБ)
SEARCH_TIMEOUT_MULT=1       # множитель всех таймаутов поиска (1..4)
```

### Защита IP (менять осторожно)
```
AVITO_HTML_RETRIES=2        # повторов на страницу; больше = сожжённый IP
AVITO_ENABLE_MOBILE_API=0   # мобильный API мёртв, включать не нужно
AVITO_PREROTATE_SEC=150     # смена IP перед запросом
AVITO_IP_BUDGET=12          # запросов на один IP до ротации
AVITO_MAX_BLOCKS=4          # блокировок подряд до остановки цикла
AVITO_SUBNET_COOLDOWN_SEC=120
```

### Необязательные
```
SPFA_API_KEY=...            # cookies для Авито; сервис нестабилен, не обязателен
AVITO_COOKIE=...            # свои cookies из браузера (запасной вариант)
RU_SOCKS_PROXIES=socks5://...,socks5://...   # пул чистых РФ SOCKS5
AUTORU_API_TOKEN=...        # токен apiauto.ru, если появится
```

## Какой нужен IP

Это выяснялось дольше всего:

- **Годится**: чистый российский резидентный или SOCKS5-адрес; мобильный со
  сменой IP — при условии бережного расхода запросов.
- **Не годится**: дата-центровые IP (Railway и подобные) — Авито блокирует сразу.
- Мобильные пулы операторов частично помечены Авито: смена адреса **внутри одной
  подсети** не помогает, нужна смена оператора/города.

В коде остался пул РФ SOCKS5 из рабочей версии (`_AUTORU_PROXIES_DEFAULT`),
Авито пробует его после мобильного прокси.
